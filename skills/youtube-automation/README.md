# youtube-automation

Skills para planejar e automatizar canais de YouTube (identidade de canal, ideias de vídeo, prompts para geração de música/imagem/animação por IA).

## Skills disponíveis

| Skill | O que faz |
|---|---|
| [`canal-youtube-musica-ambiente`](canal-youtube-musica-ambiente/SKILL.md) | Cria a identidade visual e musical de um canal de música ambiente (foco, relax, estudo, flowstate, sono) e gera sugestões completas de vídeo: thumbnail/imagem (estática ou com prompt de animação em loop), título, descrição e prompts de música para o YuE2 (ComfyUI). |

## Instalar só este segmento

```bash
npx skills add mathias-cn/skills/skills/youtube-automation/canal-youtube-musica-ambiente
```

Veja o [README principal](../../README.md) para as outras formas de instalação.
