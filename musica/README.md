# musica

Skills de teoria e composição musical, usadas como base por outras skills deste repositório (ex. geração de prompts de música por IA).

## Skills disponíveis

| Skill | O que faz |
|---|---|
| [`music-composition`](music-composition/SKILL.md) | Skill completa de teoria musical e composição (harmonia, melodia, forma, ritmo/groove, orquestração, mais de 24 gêneros, songwriting, crítica e ensino). **Fork verbatim** de [`SJY051/music-composition`](https://github.com/SJY051/music-composition) — ver `music-composition/VENDORED-FROM.md` para origem, commit e licença (CC BY 4.0). |

## Instalar só este segmento

```bash
npx skills add mathias-cn/skills/musica/music-composition
```

Veja o [README principal](../README.md) para as outras formas de instalação.
