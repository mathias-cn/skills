# marketing

Skills voltadas para prospecção, vendas e aquisição de clientes.

## Skills disponíveis

| Skill | O que faz |
|---|---|
| [`prospeccao-vendas-sites`](prospeccao-vendas-sites/SKILL.md) | Playbook de prospecção e venda de sites e landing pages para pequenos negócios: garimpo de leads, abordagem fria (método GIC), follow-up, prévia, reunião, objeções, preço, nichos e pós-venda. |

## Instalar só este segmento

```bash
npx skills add mathias-cn/skills/marketing/prospeccao-vendas-sites
```
